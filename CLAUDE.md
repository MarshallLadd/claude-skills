# Claude Skills — Personal Skill Library

This directory is a personal workspace for authoring and iterating on Claude Code skills.

## Purpose

Skills stored here extend Claude's behavior across all projects. Each skill lives in its
own subdirectory with a `SKILL.md` file that Claude loads on demand.

## Structure

```
skills/
├── <skill-name>/
│   └── SKILL.md       # Skill instructions and frontmatter
```

## Branching

See `github-flow` skill for branch and PR conventions.
