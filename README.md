# claude-skills

<!-- One-line description of this project -->
Personal Claude Code skill library for extending Claude's behavior across projects.

## Overview

<!-- What does this project do? Why does it exist? -->
A collection of custom skills that Claude Code loads on demand. Skills are organized
by domain and stored as `SKILL.md` files within named subdirectories.

## Getting Started

<!-- Prerequisites, installation steps, and first-run instructions -->
Skills in this directory are automatically available to Claude Code sessions that
have this path registered as a skills source.
